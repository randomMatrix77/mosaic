# Mosaic v0.1 — Complete UI handoff v2

Start with `Mosaic_v0.1_UI_v2_Developer_Contract.md` for screen behavior, colors, component dimensions, Compose state, and acceptance tests.

- `screens/`: ten **separate rendered screen references**, not a single composite.
- `Mosaic_v0.1_Separate_Icons_and_Graphics.zip`: individually authored SVG, Android VectorDrawable, PNG, branding, empty states, and design tokens. Unzip this file to import into the Android project.
- `prototype/index.html`: interactive visual **demo**; it uses dummy data and does NOT prove those flows work. Keep the `assets/` folder alongside it.

No microphone or audio control is included or permitted in v0.1.
